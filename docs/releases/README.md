# Cartograph Release Packets

Release packets are the repo-local proof trail for Cartograph releases.

Cartograph follows the Release Foundry Catalog #6 contract:

- Public by default when PII, secrets, license conflicts, and release-blocking
  security findings are absent
- Apple Developer ID macOS release lane first
- No shipped claim until artifact, receipt, portfolio update, and install/smoke
  verification all exist
